# Honest Ink — the classroom foundry

> Free teacher tools for the liberation of the minds of all, for all time.

**Honest Ink** is a family of teacher-facing authoring tools descended from Writer's Kiosk: local-first by instinct, district-governable when cloud inference is used, bounded in purpose, editable by the teacher, and capable of turning the physical classroom into useful instructional artifacts. Its application code, tests, and first-party recipes are GNU GPL-3.0-or-later; documentation, original printable content, and third-party assets follow the separate boundaries below. **Open Classroom Foundry** remains the repository and internal engineering name.

The whole family lives on one reusable grammar:

> **Capture or import → interpret → constrain → scaffold → let the teacher verify → render → print/export → preserve only what is worth preserving.**

The machine never appears to be the master teacher. The teacher remains the accountable author, editor, witness, and final decision-maker; the software is the extraordinarily fast press, compositor, translator, accessibility bench, and apprentice.

*The public product and renamed public module identities are governed by [ADR-006](docs/adr/ADR-006-public-name-honest-ink.md), [ADR-008](docs/adr/ADR-008-public-module-display-names.md), and the lesson-design correction in [ADR-009](docs/adr/ADR-009-strandplan-display-name.md), with counsel review still required before release. Repository, namespace, project, recipe, schema, and diagnostic identifiers remain stable compatibility contracts.*

## Status

**0.7.0-alpha — the software runs, and it is not 1.0.** The Windows desktop application works offline through three real doors: a **Press Room** of 56 deterministic printable engines across 23 recipes; **SequenceSlate — Visual Support Studio**, engineering-mode-complete as a prototype but still awaiting the constitutionally required AAC/SLP co-design and human evidence; and one generated **Built-in Studios** surface exposing ten module doors and eleven modes. Eight modes carry synthetic Green starters. Access Remix is visible but has no catalog build delegate or public remixer API until protected specialist review establishes a non-keyboard purpose authority; arbitrary typed SequenceSlate content remains purpose `Unknown` and cannot unlock it. The two district-governed modes are likewise visible but unavailable. Gate B presents the exact semantic elements, exact source when one exists, and a visibly unapproved visual derivative; approval stays disabled until the embedded browser completes the exact current revision and render profile and its DOM image is complete with positive bounds. Malformed or unready images fail closed. Projects save atomically to the open `.ocfproj` format, reopen through a hostile-package-aware reader and explicit Green preflight, recover validated asset bytes for Foundry rendering and exact resave, and have an advisory side-by-side compatibility-preparation host for a future managed version change. **Evidence is commit-scoped.** The exact `main` source baseline inherited at the [current handover's](docs/handover/2026-09-03-bounded-commission-hardening.md) local-closing cutoff and recorded in the [evidence ledger](docs/evidence/evidence-ledger.json) is `e8574d785dfc154b1c86ca125a0d45dde044f466`: CI recorded **2,013/2,013** tests and 92.8% core-and-module line coverage, and CodeQL recorded a clean SARIF across one file. The later merge `d851c6c2611147a34243b38b874831ccded54f3e` adds only the next documentation/evidence record. At that dated cutoff the bounded-commission branch had local evidence only; this snapshot neither predicts later hosted runs nor transfers an earlier hosted result to a later branch or `main` revision. Any later hosted status must be read from the exact GitHub run and a corresponding evidence record, not inferred from this paragraph. When run, CI requires warnings-as-errors, full formatting, an 80% core-and-module coverage floor, full-history secret scanning, direct and transitive vulnerability audit, locked restores, a repository/build CycloneDX inventory, a project-dependency inventory for `Foundry.App.WinForms` (not an OS/framework or release-artifact SBOM), and byte-for-byte sample determinism within and across the Windows and Linux producers. CI and CodeQL are post-push evidence and release-policy requirements. The inherited handover records an active `main` ruleset measured 2 September 2026: pull requests and the four actual check contexts are required, deletion and non-fast-forward pushes are blocked, and merge commits are the only allowed merge method.

**What is honestly not done.** No real second chrome language is shipped. A deterministic reviewed-string packet, strict catalog validator, RTL layout path, and exact-file build allowlist are ready, but the allowlist is deliberately empty until the multilingual seat supplies and reviews an actual translation. Access Remix cannot build until the protected seats establish and review a purpose-authority route that cannot be granted by typed content. ReteachSignal — Formative Evidence and Rubric Relay cannot build until written district authorization exists; visible doors do not waive either gate. The admitted 0.7 standalone `snapshot.html` stays on its frozen semantic symbol placeholders even though Foundry itself restores validated asset visuals; visual continuity outside Foundry requires a new documented renderer/version route, not a silent rewrite. The managed-upgrade ADR and runbook remain proposed; the repository has a tested compatibility-preparation seam, not a packaged or managed-device-proven upgrade and rollback path. It does not install, version, sign, distribute, or replace an application. Pre-sign and post-sign packaging routes are structurally tested but were not run. Packaging contracts are designed and structurally tested to fail closed while `EngineIdentity` says `0.7.0-alpha`, compiled assembly metadata still says `1.0.0`, and the old unsigned `v0.7.0-alpha` tag identifies an earlier commit; resolving those identities, tagging, and signing are typist acts. The build is **unsigned**—unsigned pre-sign inputs are not a release—and there is no installer. **No pilot or Atlas priority session has run.** A six-week pilot structure and draft instruments exist, but every participant-facing instrument is held until the typist issues and approves one exact corrective proposal, the initial cohort validly enacts that same participation-term version, each applicable consent/use choice is recorded, and the withdrawal right and route are separately explained and acknowledged; no opening date is authorized. See the [human-gates coordination plan](docs/pilots/human-gates-coordination-plan.md). The second maintainer's seat is open, and the bus factor is one.

The audited Writer's Kiosk baseline (commit `c2b670b`, 75 passing tests) lives at [Spacejunk-io/writers-kiosk-csharp](https://github.com/Spacejunk-io/writers-kiosk-csharp); its reusable components were refactored behind interfaces during Release 0.0 rather than copied here wholesale. Release-readiness is tracked honestly, item by item, in the [1.0 hardening checklist](docs/release/hardening-checklist.md) — every open human row there is a reason this is not 1.0.

## The liberation test

This program advances educational liberation only if its source is available, modifiable, and redistributable; existing projects remain openable and editable without a cloud connection or subscription; it uses an open documented project format; it requires no proprietary symbol set; it supports more than one inference provider and performs deterministic authoring without any model; it records rights and provenance rather than laundering assets through generation; and it never converts access support into compliance, surveillance, diagnosis, grading, or placement.

Three commitments beyond the code: a **paper-first guarantee** (every module's primary output is fully usable with zero learner devices), a **time-to-artifact budget** declared per recipe and measured in pilots, and a **minimum hardware covenant** (a 2015-era machine stays on the test bench permanently — donated hardware is where liberation actually happens).

## Data lanes, in one breath

**Green** — teacher-created, public-domain, openly licensed, staged, or generic content: save-friendly. **Amber** — anything that could link back to a learner: ephemeral by contract, separately governed, structurally gated. **Restricted** — IEP/504, medical, disciplinary, disclosure, and recipient data: blocked through 1.x. The lane follows the content and every derivative, never the operator, module, or device. Details: implementation plan §4.
