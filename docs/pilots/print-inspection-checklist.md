# Physical print inspection — checklist

**For:** week 3 of the staff pilot · **Needs:** a real duplex-capable printer, a metric ruler, scissors, a bone folder or ruler edge for creasing · **Inspectors:** one educator seat + the typist; both sign

The renderer promises millimeter truth; paper is where the promise is kept or broken. Print at **100% scale ("Actual size")** — the first defect this checklist ever catches is usually a driver's helpful "Fit to page."

## A. Millimeter truth (Deterministic Press)

| Check | Method | Pass bar | Measured | ✓/✗ |
|---|---|---|---|---|
| 5 mm graph paper | Ruler across 10 cells at page center and at one corner | 50 mm ± 0.5 mm, both places | | |
| Ruled line weight | Loupe or close look: lines crisp, not doubled/aliased | No visible stair-stepping at arm's length | | |
| Number line subdivisions | Count ticks against the recipe's parameters | Exact count, even spacing by ruler | | |
| Clock face | 60 minute ticks present, 12 emphasized, hands legible | Count and look | | |
| Handwriting sheet baselines | Measure ascender/x-height/descender bands | Match declared mm sizes ± 0.5 mm | | |
| Margins | Measure all four on one Press page | ≥ declared margin; nothing clipped by printer's unprintable zone | | |

## B. Booklet imposition

Print one 8-page booklet duplex ("flip on long edge"), fold, nest, and staple.

| Check | Pass bar | ✓/✗ |
|---|---|---|
| Page order reads 1→8 after folding | No hunting, no upside-down pages | |
| Duplex backs align | Hold a leaf to the light: front/back content areas coincide | |
| Gutter | Inner margin absorbs the fold; no text swallowed | |
| Creep | Outer edges of inner leaves not clipped | |

## C. Flashcards

| Check | Pass bar | ✓/✗ |
|---|---|---|
| Cut lines | Cutting along them yields uniform cards; no content bleeds across a cut | |
| Front/back registration | Duplex pairs match after cutting (answer belongs to its question) | |

## D. Classroom distance and hands

| Check | Pass bar | ✓/✗ |
|---|---|---|
| Task-strip symbols at 1 m | An adult at arm's-length-plus reads each symbol unambiguously | |
| Task-strip text at desk distance | Learner-facing type comfortably legible; teacher notes clearly subordinate | |
| Text scale variants | Print one strip at an enlarged `TextScalePercent`; layout holds, nothing collides | |
| Bilingual strip | Both languages print with correct shaping — Arabic joined and right-to-left, not disjointed | |
| Grayscale printer | All of the above on a mono laser: nothing depends on color alone | |

## E. The homely trials

- Fold a First/Then board in half for a pocket: does the fold land between panels?
- Leave a Press page in sunlight on a dashboard for a day (the laminator test's poor cousin): still legible?
- Photocopy a printed strip once (teachers will): survives a generation?
