# Physical print inspection — checklist

> **NOT READY FOR PARTICIPANT OR REVIEWER USE.** The typist has not issued and
> approved an exact corrective proposal, and the initial cohort has not validly
> enacted the same consent, withdrawal-right, credit, compensation, contribution,
> or private-record terms. A
> private typist-only mechanical dry run may find defects but closes no council,
> protected-seat, or pilot row. Do not collect a signature, reviewer judgment,
> or public evidence record until that same version is validly enacted, each
> applicable choice is recorded, and the
> withdrawal right and route are separately acknowledged. The compensation
> policy's counsel/accountant, authorized-route, private-ledger, exact-rate, and
> quarterly-cap prerequisites must also be satisfied before reviewer use.

Before any future reviewer run, read back that the lawful-payment route was
reverified. If the reviewer separately elected compensation, disclose the full
rate and confirm it fits the remaining quarterly cap before scheduling; once the
session begins, stopping or withdrawing does not forfeit that rate. If the
reviewer declined compensation, record zero and no retroactive amount. The
private ledger also records the required district-time/no-double-payment
attestation before scheduling.

**For:** H6 physical-print review, only after H0–H5 records are frozen and the [bounded-commission review ledger's entry conditions](../council/bounded-commission-review-ledger.md#entry-conditions) are satisfied · **Needs:** a real duplex-capable printer, a metric ruler, scissors, a bone folder or ruler edge for creasing · **Mechanical reviewer:** one constituted print/educator reviewer owns the mechanical finding · **Instrument operator:** the typist attests only the exact artifacts, printer/settings, and execution they operated

The renderer promises millimeter truth; paper is where the promise is kept or broken. Print at **100% scale ("Actual size")** — the first defect this checklist ever catches is usually a driver's helpful "Fit to page."

This sheet keeps authority and execution evidence separate. Sections A–D and F
inspect printing, geometry, legibility, and physical handling; the constituted
print/educator reviewer alone owns and closes those mechanical findings. The
typist may operate the instrument and record factual artifact, printer, driver,
scale, and execution details, but has no mechanical-review vote, finding,
approval, or veto unless separately constituted and qualified for that exact
review. Section E records distinct AAC/SLP, multilingual, and accessibility
judgments. An absent protected reviewer is **not reviewed**, never a mechanical
pass or fail, and neither the mechanical finding nor the typist's execution
attestation confers protected-seat authority.

## A. Millimeter truth (Deterministic Press)

| Check | Method | Pass bar | Measured | ✓/✗ |
|---|---|---|---|---|
| 5 mm graph paper | Ruler across 10 cells at page center and at one corner | 50 mm ± 0.5 mm, both places | | |
| Ruled line weight | Loupe or close look: lines crisp, not doubled/aliased | No visible stair-stepping at arm's length | | |
| Number line subdivisions | Count ticks against the recipe's parameters | Exact count, even spacing by ruler | | |
| Clock face | 60 minute ticks present, 12 emphasized, hands legible | Count and look | | |
| Handwriting sheet baselines | Measure ascender/x-height/descender bands | Match declared mm sizes ± 0.5 mm | | |
| Margins | Measure all four on one Press page | ≥ declared margin; nothing clipped by printer's unprintable zone | | |

## B. Booklet imposition

Print one 8-page booklet duplex ("flip on short edge"), fold, nest, and staple.

| Check | Pass bar | ✓/✗ |
|---|---|---|
| Page order reads 1→8 after folding | No hunting, no upside-down pages | |
| Duplex backs align | Hold a leaf to the light: front/back content areas coincide | |
| Gutter | Inner margin absorbs the fold; no text swallowed | |
| Creep | Outer edges of inner leaves not clipped | |

## D. Mechanical legibility at classroom distance

| Check | Pass bar | ✓/✗ |
|---|---|---|
| Task-strip symbol printing at 1 m | Required strokes, boundaries, and word labels remain visibly distinct; this checks print survival, not symbol meaning or recognizability | |
| Task-strip text at desk distance | Learner-facing type comfortably legible; teacher notes clearly subordinate | |
| Text scale variants | Print one strip at an enlarged `TextScalePercent`; layout holds, nothing collides | |
| Bilingual-row geometry | Both rows are present, aligned as designed, and unclipped; language correctness, shaping, and reading order belong to section E | |
| Grayscale printer | All of the above on a mono laser: nothing depends on color alone | |

## E. Protected judgments — separate records, separate owners

Do not complete a row without its named seat. Record **not reviewed** when the seat is absent. A symbol need not be “unambiguous” to every person; the review records intended meaning, competing readings, context, teachability, and unacceptable confusion rather than manufacturing unanimity.

| Review | Required owner | Review question | Result / evidence record |
|---|---|---|---|
| Symbol meaning and recognizability | AAC user / SLP / special educator with AAC practice | For each exact symbol/version and intended use, what readings occurred, what context or teaching is required, what alternative is preferred, and does any ambiguity create an unacceptable agency or safety failure? | |
| Bilingual language and script | Multilingual educator or family liaison qualified for the exact language pair/script | Are source and target meaning, negation, locked facts, punctuation, script shaping, bidirectional order, and print reading order acceptable for this exact artifact? | |
| Printed cognitive and low-vision access | Accessibility / AT reviewer | Are hierarchy, reading order, text/symbol relationship, scale, contrast, and physical navigation usable for the reviewed access contexts? | |

These rows review one exact sample and print setup. They do not certify a symbol family, translation system, language pair, accessible format, or future artifact.

## F. The homely trials

- Fold a First/Then board in half for a pocket: does the fold land between panels?
- Leave a Press page in sunlight on a dashboard for a day (the laminator test's poor cousin): still legible?
- Photocopy a printed strip once (teachers will): survives a generation?

When separate public-record publication consent permits, file a
participant-reviewed de-identified transcription as
`docs/evidence/pilot/print-inspection-<date>.md` with the measured values,
explicit `not reviewed`, `limited`, and `hold` states, factual paraphrases of qualitative findings,
and one issue per failed check. A refusal leaves the public evidence row open.
Keep signed originals, reviewer identities, and exact participant wording with
the private custodian. Exact wording never enters Git unless the applicable
content license has been chosen, the author separately assents to those exact
contribution terms, and the publication choice covers that wording. Public
credit remains a separate choice. A driver-dependent failure is still a
failure — the fix may be documentation ("set actual size"), but it must be
written before the classroom rung. Never use the mechanical verdict to close a
protected row, and never generalize one exact protected review beyond the
sample, language/script, symbols, and access contexts actually inspected.
