## II. The menu, ranked by value-per-risk in this window

Rewire `WindowsPdfPrinter` to prefer the native vector-first PDF for vector documents (Edge remains the fallback for HTML-shaped ones), put a **Print** button on both surfaces behind the same structural gate, and build **Booklet Binder re-imposition over real PDFs**: the existing, proven signature arithmetic composes with the PDF writer's transform matrices to emit 2-up saddle-stitch sheets natively — the copier arithmetic teachers do wrong, done right, as one file. **DoD:** a press artifact reaches a physical printer from the surface with no browser open; imposed booklet PDFs byte-deterministic, page order re-proven at the PDF layer; print failures land in the speaking status, never a dialog trap. *Medium-large.*
