# Handover — Honest Ink is the only name (10 September 2026)

**What this was.** A naming change the typist directed in session: rename the GitHub repository to `honest-ink`, name the program Honest Ink without qualification, and remove the retired in-house engineering title "Open Classroom Foundry" from the documentation. [ADR-011](../adr/ADR-011-honest-ink-is-the-only-name.md) is the governing record and supersedes ADR-006 clause 2. Read it first; this handover explains only the boundaries and the traps.

No release, tag, publication, admission, schema, or protected-seat position moved. Every hold that stood on 6 September still stands.

## What the typist still holds

1. **The published site is dark, and only you can bring it back.** GitHub redirects repository URLs but does **not** redirect project Pages URLs. `honest-ink-inc.github.io/open-classroom-foundry/` stopped resolving at the rename; `honest-ink-inc.github.io/honest-ink/` serves nothing until **you** dispatch `Publish site` from the Actions UI. That workflow is `workflow_dispatch` only and no agent ran it. Nothing is outstanding in the code: `SiteBuilder.RepositoryBase` is updated and every link the generator emits is same-directory relative, so a dispatch is sufficient.

2. **The vacated name must never be reused.** `honest-ink-inc/open-classroom-foundry` is now a redirect that frozen records depend on. Creating anything at that path — in this organization or after a transfer — silently breaks every historical link at once, and the breakage is invisible until someone follows one.

3. **The district packet still names a retired engine.** [gate-3-readiness-packet.md](../district/gate-3-readiness-packet.md) line 3 reads `Covers: Honest Ink (engine: Open Classroom Foundry, v0.7.0-alpha, GPL-3.0-or-later)`. That sentence is now false. It was **not** changed here: AGENTS.md places the district instrument behind a human hold, and this is an instrument addressed to district IT, privacy, and safeguarding readers rather than a description of the repository. It also still carries `v0.7.0-alpha` while the engine is `0.8.0-alpha`. Both belong to the same human pass.

4. **The contributor attribution is referred to counsel, not settled.** `NOTICE.md` and the thirteen `creator` records in `assets/symbols/manifest.json` still read "Open Classroom Foundry contributors". The typist chose to leave them and to raise them at the pre-release counsel checkpoint. ADR-011 clause 6 records why, and the trap is in the next section.

## The traps, so the next hand does not spring them

**The symbol manifest is a guard that repairs itself into a lie.** `assets/symbols/manifest.json` is hashed *whole*. Its digest is pinned in `tests/Integration/AssetCatalogTests.cs`, pinned again as `AppServices.ExpectedShippedSymbolManifestSha256`, and enforced at startup, where a mismatch throws `asset.unexpected-build-identity` and the shipped application refuses its own symbol pack. Edit a `creator` string and the test goes red correctly. The obvious repair — recompute the digest, update both pins — turns CI fully green while a CC0 rights record has been quietly rewritten and the provenance fence re-pinned to the new bytes. The guard fires correctly and the repair defeats it. Do not make that repair; the string is a rights question, and rights questions are not engineering decisions.

**`EngineIdentity.InternalId` is not a name and must not be renamed.** It stays `OpenClassroomFoundry` under ADR-011 clause 5. Renaming it is invisible to CI — no test pins its value, and it reaches no byte-compared artifact (all forty generated samples were regenerated during this pass and matched the frozen candidate manifest hash for hash, with the identifier present in none of them). It is visible only on disk, where it is the sole root segment of the teacher's project library, the district policy directory, the preferences file, and the MSAL token cache, with no migration code anywhere. `JsonDistrictPolicyProvider.Load` returns `DistrictPolicy.Offline` when the policy file is absent, because absence is a legitimate state — so moving that directory demotes every managed district to Offline and Green-only with no message, no log, and no failing test. A change CI cannot see and a school's IT department can is exactly the shape this repository refuses.

**A repository-wide find-and-replace would have done real damage.** It would have retitled the dated review record in `docs/reviews/masters-review-1.0.md`, rewritten quoted outreach correspondence in `docs/educator-council.md`, falsified transcribed commands and hosted run URLs inside frozen evidence tables, corrupted two archival companion-document filenames cited in the implementation plan, and hit the manifest above. Six occurrences of `OpenClassroomFoundry.slnx` were deliberately left in four frozen records for the same reason; the other sixty-six were changed.

## What changed, in shape

Live governing prose dropped the retired title (`README.md`, `GOVERNANCE.md`, `NOTICE.md`, the implementation plan). The screening record and the plan's open-decision row kept their original text and gained dated amendment notes rather than edits. Live URLs moved to the new slug: `Directory.Build.props`, `SiteBuilder.RepositoryBase`, and `tools/publish.ps1`, whose canonical/legacy pair became a legacy **list** — the pair from the first move (`Spacejunk-io` to `honest-ink-inc`) was a shape, not a special case, and a second rename proved it. Every guard that pins one of those strings moved in the same commit; none was weakened. `OpenClassroomFoundry.slnx` became `HonestInk.slnx`, with its two workflows, two PowerShell callers, and thirty-six test repository-root sentinels. The application now declares `Product` and `AssemblyTitle` of `Honest Ink`, so Windows shows the program's name where it previously showed an assembly name; `Company` and `Copyright` were deliberately **not** added, because those are entity and rights assertions rather than naming ones.

## What was measured, and the one thing that could not be

Release build clean at 0 warnings and 0 errors; `dotnet format --verify-no-changes` exit 0; the built PDB carries the new canonical SourceLink mapping, neither superseded mapping, and no local repository path.

**PowerShell 7 is not installed on this workstation, so 78 of 3,078 tests could not run here.** Every one failed identically with `System.ComponentModel.Win32Exception : An error occurred trying to start process 'pwsh' ... The system cannot find the file specified.` That is a missing prerequisite, not a defect and not a sighting: AGENTS.md assumes `pwsh` exists, and the hosted Windows runner has it. The local result is therefore **2,999 passed, 78 unrunnable, 1 failed**, and the hosted conclusion in the [evidence ledger](../evidence/evidence-ledger.json) is the measurement that counts for those 78. Anyone closing work on this machine should install PowerShell 7 first, or read CI rather than a local tally.

The one genuine failure is **S-21**, already an open row in the [sightings register](../evidence/sightings-register.md): `Foundry.Tests.Integration.ProjectUpgradeOperatorHostTests.Real_console_ctrl_c_cancels_the_process_and_cleans_the_synthetic_batch` failing `Assert.Empty()` at line 605 because this workstation finishes the host's work before the console signal lands. It reproduced here in isolation exactly as the register records, reproduces at pre-rename `main`, and has never been seen in hosted CI. It is not introduced by this change, no deadline was touched, and no repair was attempted.
