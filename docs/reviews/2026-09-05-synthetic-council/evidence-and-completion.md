## Measured strengths and precise gaps

The current bounded engineering foundation deserves preservation: mandatory
review, exact revision/asset binding, inert structured rendering, hostile package
validation, registered cloud schemas, no effective Amber sink permission, and
repeatability guards. Those are distinct from the quality of teacher judgments,
the truth of supplied facts, actual accessibility or public redistribution rights.

- Scaffold Smith's packet path requires rationale fields but does not compare the
  scaffold against the original task. The separate task-entry path **already
  accepts an optional checkpoint list**; I08 proposes making its evidence purpose
  inspectable and closing the broader packet comparison gap, not pretending the
  list is absent. Its default 30-second fade criterion is a source fact; the
  recommendation to reconsider that proxy is a pedagogical judgment.
- Forumwright checks distinct participation labels, required move families and
  question-purpose/evidence fields. These checks neither prove meaningful modes
  nor supply a time-budget or contextual sensitive-topic review.
- Inquirywright's explicit unknown-rights state produces a warning whose own text
  says it does not block approval, saving or export. Its teacher-transcript flag
  is a caller assertion, not a durable authenticated verification receipt.
- KinDispatch already requires action and contact and checks locked-field
  inventory. The deadline remains optional. I16 preserves those controls and
  proposes explicit inapplicability plus meaning review; the sentence-length
  threshold and multiple-ask heuristic are not evidence of comprehension.
- Current artifact furniture and font/PDF limitations are documented. Reviewed
  synthetic LTR/RTL test catalogs are mechanical fixtures, not a claimed second
  language. The portable snapshot's symbol placeholders preserve some semantics,
  not equivalent standalone visual communication.
- ADR-010 remains Proposed. The prior accepted recipe-identity baseline remains
  immutable; this packet changes no renderer, recipe, version, migration, sample
  baseline or authority record. The plan's derivative-lane wording conflict is
  referred for accountable correction, with the stricter current boundary retained.
