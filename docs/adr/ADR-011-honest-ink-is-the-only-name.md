# ADR-011: Honest Ink is the only name; the working title "Open Classroom Foundry" is retired

**Status:** Accepted — decided by the product owner/master teacher, 10 September 2026
**Date:** 2026-09-10
**Ratified by:** Product owner / master teacher

## Context

[ADR-006](ADR-006-public-name-honest-ink.md) settled the public name on 29 August 2026 and, in its clause 2, deliberately kept "Open Classroom Foundry" as the working, repository, and internal engineering title. That was the right decision at the time: the rename surface was a single resource string plus prose, and keeping the working title cost nothing while counsel review was still outstanding.

Twelve days of documentation proved the opposite. Two names for one program forced every live governing document to carry a disambiguating sentence — README.md, GOVERNANCE.md, NOTICE.md, and the implementation plan each spent a clause explaining which name was which — and the explanation is what readers stumbled on. "Open Classroom Foundry" names nothing a reader can point at: not the program, not a namespace (`Foundry.*`), not the internal identifier (`OpenClassroomFoundry`, one word), not the file extension (`.ocfproj`), not the organization (`honest-ink-inc`). It is a title with no referent, and a project whose first invariant is that uncertainty is marked rather than plausibly completed should not carry a name of vague definition.

There is also a brand-protection reason, and it is the sharper one. If Honest Ink is filed under Class 042 for open-source development services, the public repository is the natural specimen. A specimen that resolves to a repository called "open-classroom-foundry" invites an examining attorney to read the service as named something else and the mark as ornamental. Aligning the repository with the mark removes that argument before it is made.

The product owner decided in session on 10 September 2026 to rename the GitHub repository to `honest-ink`, to name the program Honest Ink without qualification, and to remove the retired title from documentation. This ADR records that decision. Without it, ADR-006 clause 2 remains binding and the rename is undocumented drift against a ratified record.

One hazard governs the whole change. This repository's evidence is frozen: handovers, governance records, evidence ledgers, sightings registers, containment records, and dated review records state what was true when they were written. A rename is not a licence to edit them. GitHub issues a permanent redirect for a renamed repository, so every `github.com/honest-ink-inc/open-classroom-foundry/...` URL inside a frozen record keeps resolving, and rewriting one would falsify a record to fix a link that is not broken.

## Decision

1. **The program is named Honest Ink.** The full public identity remains **"Honest Ink — the classroom foundry"**, per ADR-006 clause 1 and the standing subtitle policy. That clause is untouched, and the subtitle was considered and deliberately kept in the same session that decided this ADR.

2. **ADR-006 clause 2 is superseded.** "Open Classroom Foundry" is retired as the working title, the repository title, and the internal engineering title. It is not the name of anything from this date forward, and no document, record, instrument, or interface introduces it as a current name.

3. **The GitHub repository is renamed** from `honest-ink-inc/open-classroom-foundry` to `honest-ink-inc/honest-ink`, performed 10 September 2026 under the product owner's explicit in-session authorization, which is what [AGENTS.md](../../AGENTS.md) requires for an outward-facing act. GitHub's permanent redirect keeps prior repository, issue, and clone URLs resolving, and the project relies on that redirect rather than editing historical links. **The vacated name `honest-ink-inc/open-classroom-foundry` must never be reused**, by this organization or in any transfer: creating a repository at that path silently breaks every redirect the frozen records depend on.

4. **Live governing documents drop the retired title; frozen records keep it.** A document is live if it states what is true now: `README.md`, `GOVERNANCE.md`, `NOTICE.md`, `CONTRIBUTING.md`, `SECURITY.md`, `docs/README.md`, `docs/implementation-plan.md`, `docs/idea-atlas.md`, `docs/development/`, and the ADR set. A record is frozen if it states what was true when it was written: everything under `docs/handover/`, `docs/governance/`, `docs/evidence/`, `docs/reviews/`, `docs/baseline/`, `docs/council/`, and the dated evidence citations under `docs/release/`. Frozen records are never rewritten to follow this rename — not their titles, not their quoted correspondence, not their transcribed commands, not their run URLs. `docs/reviews/masters-review-1.0.md` keeps its "# Open Classroom Foundry" heading because that is the name the review was conducted under; `docs/educator-council.md` keeps its quoted outreach message verbatim under its existing historical-working-title heading; `docs/trademark-screening.md` keeps its screening entry, which is the record that argued for this change.

5. **Compatibility contracts are not names and do not change.** These are stable machine contracts, public-name-neutral by design, exactly as ADR-006 clause 3 provided: the `Foundry.*` namespaces; `EngineIdentity.InternalId = "OpenClassroomFoundry"`; every durable path derived from it — `%USERPROFILE%\Documents\OpenClassroomFoundry\{EngineVersion}\projects` (the teacher's project library), `%ProgramData%\OpenClassroomFoundry\policy\policy.json` (the district policy), `%LocalAppData%\OpenClassroomFoundry\preferences.json`, and `%AppData%\OpenClassroomFoundry\entra-account.json`; the `.ocfproj` project-file extension, which every existing teacher file depends on; the `ocf.*` manifest format identifiers; the `OCF_*` development environment variables; and the `OCF-COUNCIL-TERMS-v1` and `OCF-COMPENSATION-v1` control identifiers.

   The district policy path is the binding reason, and it was measured rather than assumed. `JsonDistrictPolicyProvider.Load` returns `DistrictPolicy.Offline` when the policy file is absent, because absence is a legitimate state rather than an error. Moving that directory would therefore demote every managed district to Offline and Green-only **silently** — no message, no log, and no failing test, because no test pins the identifier. A change that is invisible to CI and visible only to a school's IT department is exactly the change this repository exists to refuse. The same measurement pass confirmed the identifier reaches no byte-compared artifact: all forty generated samples were regenerated, matched the frozen candidate manifest hash for hash, and contain the identifier nowhere.

6. **Rights strings are outside this decision, and are referred to counsel.** "Open Classroom Foundry contributors" in `NOTICE.md` and in the thirteen `creator` records of `assets/symbols/manifest.json` is a copyright attribution naming who held the rights, not a product name. Changing who is recorded as holding copyright is a rights act, not a rename, and this ADR authorizes none. The manifest is additionally fenced: its bytes are hashed whole, and that digest is pinned in `tests/Integration/AssetCatalogTests.cs`, pinned again as `AppServices.ExpectedShippedSymbolManifestSha256`, and enforced at application startup, where a mismatch throws `asset.unexpected-build-identity` and the shipped application refuses its own symbol pack. Editing a `creator` field would be a rights change and a shipped-integrity change at once, and the obvious repair — recomputing the digest and updating both pins — would turn a correctly firing guard green over a quietly rewritten rights record. **The product owner referred the attribution question to the pre-release counsel checkpoint in clause 7; it is open, not settled, and it is not an engineering decision.**

7. **Nothing here is clearance.** ADR-006 clauses 1, 3, 4, and 5 remain in force, including the pre-release requirement that professional counsel and formal USPTO/EUIPO screening confirm the name before any public distribution, and including the ordered fallbacks (Schoolhouse Foundry, then Inkwright) if counsel fails it. `docs/trademark-screening.md` remains evidence, not clearance. This ADR grants no AAC/SLP, accessibility, multilingual, rights, district, or council authority, and it is not a release, a tag, or a publication.

8. **The solution file is renamed** from `OpenClassroomFoundry.slnx` to `HonestInk.slnx`, because it was the most prominent surviving instance of the retired title and ADR-006 clause 2 had pinned it by name. The change is mechanical and was measured before it was made: the literal is byte-identical in all seventy-two occurrences, the file's own contents are entirely path-based and carry no product name, no NuGet lock file or `.editorconfig` or `global.json` names it, and no branch-protection context depends on it — the ruleset requires the job keys `build-and-test`, `portable-samples`, `secret-scan`, and `analyze-csharp`, none of which contains a filename. Two references are load-bearing and were changed in the same commit: `tools/CiTestEvidence.psm1`, whose default solution path is live because `tools/run-ci-tests.ps1` calls the inventory without overriding it, and the thirty-six test files that walk parent directories looking for that exact filename as the repository-root sentinel.

   The CycloneDX SBOM root component keeps the name `OpenClassroomFoundry` for now: it is set explicitly in `.github/workflows/ci.yml`, is not derived from the solution filename, and is a supply-chain component identity whose continuity is worth more than its spelling. Changing it is a separate, deliberate decision.

## Alternatives considered

**Amend ADR-006 in place.** Rejected. A ratified ADR is immutable; editing clause 2 would make the 29 August record state a decision that was not made on 29 August, and would destroy the evidence of why the two-name arrangement existed at all.

**Repository-wide find-and-replace of the retired title.** Rejected, and it is worth naming what it would have broken: it would have rewritten quoted outreach correspondence in `docs/educator-council.md`, retitled a dated review record in `docs/reviews/masters-review-1.0.md`, falsified transcribed commands inside evidence tables, corrupted two archival companion-document filenames cited in the implementation plan, altered thirteen copyright-attribution records, and changed the bytes of a manifest whose SHA-256 is pinned in three places including a runtime integrity check. The measured cost of the careless version of this change is a shipped application that refuses to start.

**Keep the dual name and merely explain it better.** Rejected. Twelve days of prose proved the explanation is the defect. A name that needs a sentence of disambiguation in every governing document is not doing a name's work.

**Rename the internal identifier and namespaces to match.** Rejected, for the measured reasons in clause 5. ADR-006 clause 3 had this right and it survives.

**Rename to `honest-ink-foundry` instead.** Rejected. It preserves the ambiguity this ADR exists to remove, and it weakens the specimen argument in Context by putting a second word between the mark and the repository.

## Consequences

The program has one name in every live document, and readers stop meeting a title with no referent. Frozen evidence is untouched, which means the repository's historical record still shows plainly that the program was once called something else and when it stopped being called that — the honest outcome, not an embarrassment to be scrubbed.

**The published site goes dark at the rename, and only the typist can restore it.** GitHub redirects repository URLs but explicitly does *not* redirect project GitHub Pages URLs. `https://honest-ink-inc.github.io/open-classroom-foundry/` stopped resolving the moment the repository was renamed, and `https://honest-ink-inc.github.io/honest-ink/` serves nothing until `.github/workflows/site.yml` is dispatched again. That workflow is `workflow_dispatch` only and is a typist act under ADR-006's counsel checkpoint and AGENTS.md; no agent runs it, and none ran it for this change. The generated site itself needs nothing further: every internal link it emits is same-directory relative, and `SiteBuilder.RepositoryBase` was updated in this change, so a dispatch is sufficient and no code change is outstanding.

Old repository URLs survive on GitHub's redirect, and the project now depends on that redirect — which is why clause 3 forbids ever reusing the vacated name.

Release metadata gained a second superseded source mapping. `tools/publish.ps1` already carried a canonical/legacy pair from the first move (`Spacejunk-io` to `honest-ink-inc`); it now carries a legacy *list*, because a second rename proved the pair was a shape, not a special case. Any release PDB that retains either superseded mapping still fails the check.

This decision is reversible in principle by a further ADR, but not cheaply: the repository rename vacates a name that must then never be reused, and the redirect is one-way.
