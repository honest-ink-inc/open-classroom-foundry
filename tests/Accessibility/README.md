# Accessibility test suite

This directory contains machine evidence for the exact 1366×768 non-breaking minimum-floor contract. Its tests exercise layout, clipping, naming, and scroll reachability; they do not turn the floor into the product's design target.

Accessibility and language evidence is intentionally distributed across several suites. The [release traceability matrix](../../docs/release/release-requirement-test-traceability.md#accessibility-and-language) maps those requirements to their implementation and tests and records the remaining human and protected evidence. The tests here do not claim NVDA/Narrator review, contrast or high-contrast evidence, 200% zoom proof, human reading-order review, or an ACR/VPAT.
