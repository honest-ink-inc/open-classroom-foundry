# Accessibility test suite

This directory contains hermetic machine evidence for the 1366×768 practical functional-floor contract, using 1366×728 and 1366×720 reference working-area profiles. Essential controls, status, and recovery paths must remain readable and reachable, while reflow, wrapping, and genuine scrolling are valid responses to the smaller working area. The matrix includes neutral 100%, pseudo 125%, hermetically geometry-and-font-scaled neutral and pseudo 200%, and exact-hash test-only synthetic reviewed-catalog LTR/RTL projections at 100% and 200%; the latter are expressly not protected-seat evidence and the production catalog allowlist remains empty. These live-client-tree tests exercise layout, clipping, naming, scroll reachability, export-state geometry, essential visual viewports, and inherited plus explicitly authored font metrics. They neither turn the floor into a fixed-canvas design target nor provide physical-device, `DeviceDpi`, non-client, or top-level shown-window proof.

Accessibility and language evidence is intentionally distributed across several suites. The [release traceability matrix](../../docs/release/release-requirement-test-traceability.md#accessibility-and-language) maps those requirements to their implementation and tests and records the remaining human and protected evidence. The tests here do not claim NVDA/Narrator review, contrast or high-contrast evidence, physical/OS 200% zoom proof, human reading-order review, or an ACR/VPAT.
